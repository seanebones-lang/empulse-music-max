## 📝 Documentation Standards

### Writing Documentation

When adding new documentation:

1. **Use Markdown** - All docs in Markdown format
2. **Include Examples** - Code examples for clarity
3. **Keep Updated** - Update when code changes
4. **Be Clear** - Write for different skill levels
5. **Add Links** - Cross-reference related docs

### Documentation Structure

```markdown
# Title
Brief description

## Section
Content here

### Subsection
More content
```
